# 🚲 Analyzing Smart City Bike Sharing Data Using Power BI

## 📌 Project Overview

Public bike-sharing systems generate large amounts of station-level data across different cities. Analysing this data helps understand bike availability, station performance, operational efficiency and urban mobility patterns.

This project focuses on analysing a Smart City Bike Sharing dataset using **Microsoft Power BI** to understand station performance, bike availability and operational patterns across cities.

The project demonstrates my practical skills in data cleaning, data transformation, data modelling, DAX calculations and interactive dashboard development.

The main goal is to convert raw bike station data into meaningful insights that can support better operational planning and decision-making.

## 🎯 Project Objectives

- Analyse bike station performance across different cities.
- Identify the total number of bike stations and their operational status.
- Evaluate available bikes and empty docking spaces.
- Compare station availability across different cities.
- Analyse open, closed and other station status categories.
- Understand station operational efficiency.
- Identify geographical distribution of bike stations using map visualization.
- Develop an interactive Power BI dashboard to monitor bike-sharing performance.

## 📂 Dataset Information

- **Dataset Name:** Smart City Bike Sharing / Bike Station Dataset
- **Domain:** Urban Mobility and Transportation Analytics
- **Data Type:** Bike station-level operational data
- **Tool Used:** Microsoft Power BI Desktop

### Important Dataset Attributes

| Attribute | Description |
|---|---|
| STATION KEY | Unique station identification key |
| NAME | Name of the bike station |
| CONTRACT NAME | City or operating contract associated with the station |
| STATUS | Current station status |
| AVAILABLE BIKE STANDS | Number of available bike stands |
| LATITUDE | Geographic latitude of the station |
| LONGITUDE | Geographic longitude of the station |
| BANKING | Indicates whether banking facilities are available |
| BONUS | Indicates whether the station has bonus status |

## 🔄 Project Workflow

1. **Data Import:** Imported the bike station dataset into Power BI Desktop.
2. **Data Cleaning:** Checked data quality, missing values, data types and inconsistent records.
3. **Data Transformation:** Used Power Query Editor to prepare and organize the dataset.
4. **Data Modelling:** Organized the station and city information for reporting.
5. **DAX Calculations:** Created measures to calculate station performance and bike availability.
6. **Data Visualization:** Developed KPI cards, bar charts, column charts, donut charts and geographical maps.
7. **Dashboard Development:** Combined important visualizations into an interactive dashboard.
8. **Data Analysis:** Analysed station status, city performance and operational efficiency.

## 📐 Key DAX Measures

The following measures are included in the Power BI project:

| Measure | Purpose |
|---|---|
| Total Bike Capacity | Calculates the total bike stand capacity |
| Open Stations | Calculates the number of open stations |
| Total Stations | Calculates the total number of stations |
| Available Bikes | Measures available bike stands |
| Available Empty Docks | Calculates available empty docking spaces |
| Closed Stations | Calculates the number of closed stations |
| Bike Availability % | Measures bike availability as a percentage |
| Station Operational % | Measures the operational percentage of stations |
| Total Cities | Calculates the number of cities represented |
| Invalid Capacity Records | Identifies records with invalid capacity information |

## 🔍 Business Analysis and Insights

### 1. Descriptive Analysis – What Happened?

- Identifies the total number of bike stations across the selected cities.
- Shows the number of open and closed stations.
- Measures the total available bike stands and empty docking spaces.
- Displays bike availability percentage.
- Shows the geographical distribution of bike stations.

### 2. Diagnostic Analysis – Why Did It Happen?

- Compares station availability across different cities.
- Helps identify cities with fewer available bike stands.
- Examines the distribution of open and closed stations.
- Helps identify differences in station operational performance.
- Allows comparison of banking and bonus station features.

### 3. Predictive Analysis – What May Happen Next?

- Cities with consistently low bike availability may require closer monitoring.
- Stations with high usage or limited availability may require additional capacity planning.
- Operational patterns can help identify stations that may need maintenance.
- Historical station information can support future bike availability planning.
- Regular monitoring may help identify possible operational issues early.

### 4. Prescriptive Analysis – What Should Be Done Next?

- Improve bike availability at stations with limited available bikes.
- Monitor closed stations and investigate operational issues.
- Plan additional bike capacity in areas with higher demand.
- Maintain sufficient empty docking spaces for returning bicycles.
- Use geographical station information to improve station distribution and operational planning.

*Note: Predictive and prescriptive points are recommendations and possible future applications, not verified forecasting results.*
